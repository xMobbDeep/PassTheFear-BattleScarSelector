# Notices

This repository contains source code for a third-party Battle Scar selector and its BepInEx plugin. The prebuilt selector in `dist/` includes the catalogue, effect text, and artwork needed for the standalone player interface. The game executable, `GameAssembly.dll`, BepInEx files, generated IL2CPP interop assemblies, and other game binaries are not included.

The game and its art assets remain the property of their respective owners. Use the selector with your own legally installed copy of *Pass The Fear*. The local extraction inputs used for a source build are kept out of Git under `developer/private-assets`.

BepInEx is an external project licensed under LGPL-2.1. See the [official BepInEx repository](https://github.com/BepInEx/BepInEx) for its license and source.
